Do not seek to hidden future data or stage a precomputed final recap. A paused replay can be restored between takes using its browser session; a fresh final take should reproduce the same session-independent fixture behavior.

Before recording: start with mock defaults, close personal tabs, rehearse mouse/keyboard, confirm chosen card and overlay are eligible, validate no fixture phase plan is visible, check 360px/1440px screenshots, and have the football expert approve wording.
